3. Back up the encryption key
{{ if .Values.existingSecret }}
   You supplied "{{ .Values.existingSecret }}". Keep it safe.
{{- else }}
   storeEncryptionKey protects setup keys and API tokens at rest, and the
   chart generates it once. Losing it means losing access to that data, and
   `helm uninstall` deletes it. Save a copy now:

     kubectl get secret -n {{ .Release.Namespace }} {{ include "netbird.secretName" . }} -o yaml > netbird-secrets.yaml
{{- end }}

4. Check it over
